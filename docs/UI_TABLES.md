## 4. 공모주 일정 스트립

| 순서 | 컬럼 | 빈 값 규칙 |
| --- | --- | --- |
| 1 | 청약 상태/일차 | 청약 날짜만 있으면 날짜 범위만 표시; 시간을 추정하지 않음 |
| 2 | 종목명/구분 | `IPO`, `SPAC`, `실권주` 중 원천이 제공한 구분 |
| 3 | 청약 기간 | `시작일 ~ 종료일` |
| 4 | 공모가 | `—` |
| 5 | 참여 증권사 | OpenDART 인수인 이름, 없으면 `—` |

## 5. 공모주 증권사 비교표

| 순서 | 컬럼 | 빈 값 규칙 |
| --- | --- | --- |
| 1 | 증권사/인수 역할 | `—` |
| 2 | 인수 수량 | `—` |
| 3 | 일반청약/균등/비례 배정 풀 | 각 값 `—` |
| 4 | 현재 전체 경쟁률 | `—` |
| 5 | 현재 비례 경쟁률 | `—` |
| 6 | 청약 건수 | `—` |
| 7 | 현재 균등 예상 | `—` |
| 8 | 예상 마감 비례 경쟁률 | `—` |
| 9 | 예상 균등 예상 | `—` |
| 10 | 1주 예상 필요 증거금 | `—` |
| 11 | 수수료/최소·단위 | `—` |
| 12 | 원천 상태/기준시각 | `미제공` 상태와 출처를 함께 표시 |

`전체 경쟁률`과 `비례 경쟁률`은 동일한 열로 합치지 않는다. 넓은 표는 카드 내부에서만
가로 스크롤한다.

## 6. 신청 주수별 계산표

| 순서 | 컬럼 | 빈 값 규칙 |
| --- | --- | --- |
| 1 | 신청 주수 | 증권사 최소/단위가 없으면 계산 비활성 |
| 2 | 필요 증거금 | 공모가 또는 증거금율이 없으면 `—` |
| 3 | 비례 기대 | `broker-proportional` 비율이 없으면 `—` |
| 4 | 균등 기대 | 같은 계산 기준의 균등 예측값이 없으면 `—` |
| 5 | 총 기대 | 비례와 균등이 모두 있을 때만 표시 |

현재 기준은 현재 균등 예상값, 예상 마감 기준은 예상 균등값만 사용한다.
