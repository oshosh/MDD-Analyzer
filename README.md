## ✨ 왜 MDD Analyzer인가요? (Key Value Proposition)

| 🛡️ **원화(KRW) 실질 리스크 분석** | 🎯 **통계적 매수 우위(Buy Strategy)** | ⚡ **한국 주식 실시간 수급 동향** |
| :--- | :--- | :--- |
| 달러 주가가 떨어져도 **환율(USD/KRW)**이 상승해 내 손실을 막아주는 '환쿠션' 효과를 정밀하게 분해 계산합니다. | 과거 10년 이상의 거래일 데이터를 전수 조사하여 **"현재 낙폭 구간 진입 시 1년 후 승률과 기대 수익률"**을 제시합니다. | 장중 외국계 증권사 가집계 수급부터 **KRX 정규장 + NXT 대체거래소** 통합 5영업일 마감 이력까지 실시간 제공합니다. |

## 🎯 누구에게 필요한가요? (Target Audience)

- 🇺🇸 **미국 ETF/주식을 장기 모아가시는 분** (SPY, QQQ, AAPL, NVDA 등)
  - 고점 대비 몇 %나 빠졌는지, 과거에 이 정도 빠졌을 때 언제 회복되었는지 궁금하신 분
- 🇰🇷 **환율 변동성으로 실질 계좌 잔고 손실을 파악하고 싶은 한국 투자자**
  - 달러 가격 하락과 원화 환율 상승이 내 포트폴리오에 미친 실제 방어율을 측정하고 싶으신 분
- 📈 **하락장에서 분할 매수 적기를 찾고 계신 데이터 중심 투자자**
  - 감정이나 막연한 공포에 휩쓸리지 않고, 통계적 승률이 우수한 하락 구간(Alpha)을 포착하고 싶으신 분

├────────────────────────────────────────────────────────────────────────┤
│ 5. 🔍 RAW 데이터 100% 검증 패널 (일자별 엑셀 계산 수식 완벽 보증)      │
└────────────────────────────────────────────────────────────────────────┘

### 1. 📊 실시간 MDD & ATH 요약 패널
- **USD 기준 vs KRW 기준** 가격, 전고점(ATH), 현재 낙폭(Current Drawdown), 역사적 최대 낙폭(MDD)을 일목요연하게 비교해 드립니다.

### 2. 🎯 퀀트 기반 매수 시그널 (Buy Strategy)
- 추측성 예측이 아닙니다! 과거 동일 하락률에 도달했던 순간들만 추출하여 **"1년 후 평균 수익률"**, **"최고/최악 수익률"**, **"1년 승률"**을 1~5단계 시그널 레벨로 제시합니다.

### 3. ⏱️ 회복 탄력성 통계 (Recovery Forecast)
- "과거에 이 하락률에 진입했을 때 **30일/60일 이내에 전고점을 회복할 확률**"과 **평균 회복 소요 영업일 수**를 통계로 도출합니다.

### 4. 🇰🇷 한국 주식 전용 실시간 수급 추정 패널
- **실시간 주가 틱 정보**: 초단위 주가 변화 반영
- **당일 장중 외국계 수급 가집계**: 상위 5개 외국계 증권사 창구의 매수/매도 합산 및 순매수 추정치
- **공시 마감 5영업일 수급**: 외국인 · 기관 · 개인의 통합(KRX+NXT) 수급 및 외인 소진율 추이

### 5. 🛡️ 100% 투명한 RAW 데이터 패널
- 계산에 사용된 모든 일자별 종가, 환율, Peak, Drawdown 데이터를 시트 형태로 100% 공개하며, 오차 `1e-6` 이하의 수학적 무결성을 직접 검증하실 수 있습니다.

## ⚡ 3초 만에 시작하기 (Quick Start)

### 웹 서비스 바로가기
별도의 회원가입 없이 브라우저에서 티커(예: `SPY`, `AAPL`, `005930`)를 입력하고 바로 이용하실 수 있습니다.

### 로컬 개발 및 실행
```bash
# 1. 저장소 클론 및 패키지 설치
git clone https://github.com/oshosh/MDD-Analyzer.git
cd MDD-Analyzer
pnpm install

# 2. 로컬 개발 서버 실행
pnpm dev

# 3. 정적 타입 검사 & 테스트
pnpm typecheck
pnpm test
```

> 
> - 본 서비스의 분석 결과는 특정 주식, ETF, 금융 상품의 매수/매도 추천 또는 투자 권유가 아닙니다.
