## ✨ 왜 MDD Analyzer가 필요할까요?

투자를 하다 보면 누구나 하락장의 공포를 마주하게 돼요. 하지만 감정으로 매매하면 꼭 바닥에서 패닉 셀(손절)을 하거나 고점에서 추격 매수를 하게 돼요. 

MDD Analyzer는 이러한 문제를 수학적 통계와 스마트 퀀트 시스템으로 해결해 드려요.

- **데이터 기반의 객관적인 리스크 측정**: 고점 대비 얼마나 빠졌는지, 과거에 이 정도 하락했을 때 언제 어떻게 회복되었는지 통계로 보여줘요.
- **한국 투자자를 위한 실질 환노출 분석**: 미국 주가가 떨어져도 달러 환율이 올라 내 원화 잔고를 지켜주는 '환쿠션' 방어 효과를 정밀하게 분해해 드려요.
- **QLD 80:20 스마트 리밸런싱 시스템**: 레버리지 ETF의 치명적인 대폭락(-80%) 위험을 완벽히 방어하면서 우상향 복리 수익을 극대화해요.
- **Google Gemini AI 경기 사이클 해석**: 쏟아지는 복잡한 금융 뉴스와 거시경제 지표를 AI가 분석하여 현재 시장의 국면과 가이드를 제시해요.

## 🚀 주요 기능 한눈에 보기

### 1. 🟢 QLD 80:20 스마트 리밸런싱 계산기 & 20년 백테스트
> *"폭등할 때 일부 익절해 달러를 챙기고, 폭락할 때 아껴둔 달러로 저가 매수(줍줍)해요."*

- **스마트 비중 관리**: 주가 급등으로 주식 비중이 88%를 넘으면 초과분을 부분 익절하여 달러 현금 20%를 채우고, 75% 밑으로 떨어지면 비축한 현금으로 2분할 LOC 저가 매수를 진행해요.
- **손절 매도 완전 차단**: 현재가가 평단가 이하인 손실 구간에서는 절대 손절 매도를 허용하지 않고, 현금 추가 입금을 통해 비중을 안전하게 조절해요.
- **TradingView 20년 인터랙티브 백테스트 차트**: 2006년 상장일부터 현재까지 20년간 매월 $1,000씩 모아온 두 계좌(무지성 DCA vs EVH 스마트 계좌)의 실시간 성과를 **1일봉, 5일봉, 1달봉, 3달봉, 6달봉, 1년봉**으로 자유롭게 집계하고 캘린더로 비교할 수 있어요.
- **원클릭 주문표 복사**: 오늘 밤 미국 증시 마감에 제출할 LOC 주문 수량과 지정가를 클릭 한 번으로 복사할 수 있어요.

---

### 2. 🤖 Google Gemini AI 매크로 사이클 & 뉴스 진단
> *"수많은 금융 뉴스를 일일이 읽지 않아도, AI가 핵심 사이클을 명쾌하게 요약해요."*

- **실시간 금융 뉴스 맥락 분석**: 종목 및 시장과 관련된 최신 뉴스를 실시간으로 수집하고, Google Gemini AI가 시장에 미칠 긍정/부정적 영향을 정밀하게 해석해요.
- **4단계 경기 사이클 진단**: 현재 경제 국면이 **'회복기'**, **'활황기'**, **'과열/후퇴기'**, **'침체기'** 중 어디에 해당하는지 진단하고 투자자가 주의해야 할 리스크를 짚어줘요.

---

### 3. 📊 실시간 MDD & 원화(KRW) 환노출 실질 리스크 분해
> *"달러 주가와 내 통장에 찍히는 원화 수익률의 차이를 투명하게 밝혀드려요."*

- **USD 기준 vs KRW 기준 1:1 비교**: 미국 주식의 달러 낙폭과 원/달러 환율 변동성을 결합하여, 한국 투자자가 체감하는 **실질 원화 손실률과 전고점(ATH)**을 정확히 분해해요.
- **통계적 매수 우위(Alpha) 시그널**: 과거 10년 이상의 거래일 중 동일한 하락폭에 도달했던 구간들을 전수 조사하여 **1년 후 승률과 기대 수익률, 회복 확률**을 1~5단계 시그널로 도출해요.

---

### 4. 🇰🇷 한국 주식 실시간 수급 가집계 & 5영업일 동향
> *"장중 외국계 증권사 창구의 실시간 순매수 흐름을 포착해요."*

- **장중 외국계 거래원 가집계**: 당일 장중 상위 5개 외국계 증권사의 매도/매수 거래량을 실시간으로 합산하여 외국인 순매수 규모(원화 환산액)를 추정해요.
- **공시 마감 5영업일 기관/외인 수급 이력**: 한국거래소(KRX)와 대체거래소(NXT)를 통합하여 외국인, 기관, 개인의 5영업일 연속 수급 추이와 외인 소진율을 관찰할 수 있어요.

---

### 5. 🔍 지능형 다국어 검색 & 100% 투명한 RAW 데이터
> *"영문 티커를 몰라도 '삼성전자', '애플', '엔비디아' 한글로 바로 찾아요."*

- **Wikipedia 글로벌 다국어 파이프라인**: 한글 회사명을 입력해도 위키피디아 지식 파이프라인을 거쳐 정확한 글로벌 티커(AAPL, NVDA 등)를 찾아줘요.
- **수학적 무결성 검증 패널**: 계산에 사용된 모든 일자별 종가, 환율, Peak, Drawdown 데이터를 엑셀 시트 형태로 100% 투명하게 공개하여 오차 `1e-6` 이하의 정확도를 직접 검증할 수 있어요.

## 🛠️ 모던한 기술 스택

MDD Analyzer는 현대적인 웹 생태계의 최고 기술들로 견고하게 구축되었어요:

- **Core Framework**: [Next.js 15 (App Router)](https://nextjs.org/) & [React 19](https://react.dev/)
- **Language**: 엄격한 타입을 준수하는 [TypeScript 5.7](https://www.typescriptlang.org/)
- **Styling**: 차세대 초경량 엔진 [Tailwind CSS v4](https://tailwindcss.com/) & Material 3 디자인 시스템
- **Chart Engine**: 초고속 렌더링을 자랑하는 [TradingView Lightweight Charts v5](https://tradingview.github.io/lightweight-charts/)
- **AI Intelligence**: [Google Gemini 2.0 AI API](https://ai.google.dev/)
- **Architecture**: 기능 확장과 유지보수가 뛰어난 [FSD (Feature-Sliced Design) v2](https://feature-sliced.design/)
- **Code Quality**: 데드 코드와 미사용 의존성을 원천 차단하는 [Knip](https://knip.dev/) & [Vitest](https://vitest.dev/)

## ⚡ 빠른 시작하기 (Quick Start)

### 1. 저장소 클론 및 패키지 설치
```bash
git clone https://github.com/oshosh/MDD-Analyzer.git
cd MDD-Analyzer
pnpm install
```

### 2. 환경 변수 설정 (`.env.local`)
Gemini AI 분석 기능을 사용하려면 Google AI Studio에서 발급받은 API 키를 설정해 주세요:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. 로컬 개발 서버 실행
```bash
pnpm dev
```
브라우저에서 `http://localhost:3000`으로 접속하면 즉시 대시보드를 사용할 수 있어요.

### 4. 품질 검증 및 테스트
```bash
pnpm typecheck   # TypeScript 정적 타입 검사
pnpm lint        # ESLint 정적 코드 분석
pnpm knip        # 미사용 파일 및 데드 코드 검사
pnpm test        # Vitest 금융 수식 단위 테스트
```
