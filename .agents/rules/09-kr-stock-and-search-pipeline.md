# 🇰🇷 한국 주식 수급 및 한글 검색 규격

### 1. 한국 주식 수급 분석 규칙
- **장중 외국계 거래원 가집계**: 네이버 금융 HTML 파싱 시 1번째 수치(매도량)와 2번째 수치(매수량)를 수집한 후, `순매수량 = 매수량 - 매도량` 공식으로 정확한 순매도/순매수 부호를 도출한다.
- **5영업일 마감 확정 수급**: 통합(KRX+NXT), KRX, NXT 시장 구분을 지원하며 종가, 외인 소진율, 거래량/거래금액 단위를 일관되게 표시한다.
- **호출 제어**: 연속적 자동 Polling을 제한하고, 사용자 수동 요청 시 갱신하는 방식을 원칙으로 한다.

### 2. 한글 입력 기반 글로벌 티커 검색 규칙
- 한글 입력 시 외부 프록시 및 Wikipedia 다국어 파이프라인(opensearch → langlinks)을 거쳐 정규 영문 티커를 찾아야 한다.
- 검색 결과는 중복 티커를 제거(Deduplication)하고 Zod 스키마 검증을 필수로 적용한다.
